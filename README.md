# نظام سجلات مرضى — د. هايدي علي

## الملفات
- `schema.sql` — كل الجداول وسياسات الأمان (RLS) وبكت الصور. يتشغل مرة واحدة في Supabase SQL Editor.
- `index.html` — شاشة تسجيل الدخول
- `app.html` — التطبيق الرئيسي (قائمة المريضات، الملف، الزيارات)
- `styles.css` — التصميم (ألوان اللوجو: وردي/روز جولد)
- `i18n.js` — نصوص عربي/إنجليزي
- `config.js` — بيانات الاتصال بـ Supabase (**لازم تتعدل قبل الرفع**)
- `logo.png` — **حط هنا لوجو د. هايدي (المستخرج من الصورة اللي بعتهالي)** بنفس الاسم ده بالظبط

## خطوات التشغيل

### 1. إنشاء مشروع Supabase
- روح على supabase.com وأنشئ مشروع جديد
- من SQL Editor، شغّل محتوى `schema.sql` بالكامل مرة واحدة

### 2. تعديل config.js
افتح `config.js` وحط:
```js
const SUPABASE_URL = "الرابط بتاع مشروعك"; // من Settings → API
const SUPABASE_ANON_KEY = "الـ anon key"; // من Settings → API
```

### 3. إنشاء حسابات الدكتورة والسكرتيرة
من Supabase Dashboard → Authentication → Users → Add User، أنشئ:
- حساب الدكتورة (إيميل + باسورد)
- حساب سكرتيرة فرع 1
- حساب سكرتيرة فرع 2

بعد ما تنشئ كل حساب، انسخ الـ User UID بتاعه، وروح على SQL Editor ونفذ:

```sql
-- للدكتورة (branch_id = null معناها بتشتغل على الفروع كلها)
insert into profiles (id, full_name, role, branch_id)
values ('USER_UID_بتاع_الدكتورة', 'د. هايدي علي', 'doctor', null);

-- لسكرتيرة فرع 1 (هات الـ id بتاع الفرع من: select * from branches;)
insert into profiles (id, full_name, role, branch_id)
values ('USER_UID_بتاع_السكرتيرة_1', 'سكرتيرة فرع 1', 'secretary', 'ID_فرع_1');

-- لسكرتيرة فرع 2
insert into profiles (id, full_name, role, branch_id)
values ('USER_UID_بتاع_السكرتيرة_2', 'سكرتيرة فرع 2', 'secretary', 'ID_فرع_2');
```

### 4. حط اللوجو
احفظ صورة اللوجو باسم `logo.png` في نفس مجلد الملفات دي.

### 5. الرفع على GitHub Pages
ارفع كل الملفات في ريبو GitHub، فعّل GitHub Pages من Settings، وهيبقى عندك رابط تفتحه من أي موبايل.

## نقاط مهمة
- **مفيش تعديل أو مسح للزيارات والصور بعد الحفظ** (append-only) — أي تصحيح بيتضاف كإدخال جديد من زرار "إضافة تصحيح" تحت كل زيارة، ده متطبق فعليًا في قاعدة البيانات نفسها مش بس في الواجهة، يعني حتى لو حد حاول يعدل من مكان تاني هيترفض.
- المريضة ملف واحد مشترك بين الفرعين، والزيارات بس اللي موسومة بفرع معين.
- نظام حجز المواعيد مؤجل لمرحلة تانية زي ما اتفقنا.

## الخطوة الجاية (لو حابب)
أنصح تنقل المشروع ده لـ Claude Code قبل التسليم النهائي عشان:
- تختبر رفع الصور والكاميرا فعليًا على موبايل حقيقي
- تتأكد إن الـ RLS شغالة صح (سكرتيرة فرع 1 متقدرش تضيف زيارة لفرع 2)
- تضيف أي تحسينات قبل ما توريها للدكتورة
